# GitHub description options

Each option is character-verified at or below 350 characters by `tools/verify_launch.py`.

## Option A (recommended): capability first

HELM: a ten-prompt BHIL framework that turns client data into eye-catching, functional, Claude Code friendly dashboards in 15 original sci-fi design languages. Evidence-tiered numbers, a Narrative Tax Register for every trope, IP-clean by test, and a scaffold so the client's own Claude Code can rebind, restyle, and add panels.

Rationale: leads with the outcome, names the three differentiators (evidence tiers, narrative tax, IP-clean), and closes on the Claude Code hook that enterprise buyers care about.

## Option B: discipline first

Fictional interfaces read as complex and clear in one second. HELM keeps that discipline and drops the tropes. Ten prompts, 15 design languages with documented lineage, drift-gated tokens, CADRE agents, and a starter dashboard you can open from file://. Barry Hurd Intelligence Lab.

Rationale: strongest narrative hook; weaker on searchable keywords.

## Option C: builder first

Sci-fi dashboard framework for Claude Code. Profile data, match a design language, build a single-file HTML mockup with real bindings, QA it against WCAG AA and an IP checklist, gate it SHIP/HOLD/REWORK. 15 token sets, 4 subagents, 6 slash commands, stdlib-only validators. MIT + CC BY 4.0.

Rationale: densest keyword coverage for GitHub search; least voice.
