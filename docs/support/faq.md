# FAQ

**Can HELM make my dashboard look exactly like a specific show or film?**
No. HELM carries the grammar of a lineage (palette relationships, hierarchy device, motion) as an original design language. It never reproduces a specific screen, name, logo, glyph system, or licensed font. If you name a property, the stylist translates to the nearest catalog language and tells you it did.

**What if my data is just a description, not a file?**
SP-1 builds a synthetic dataset, marks every row SYNTHETIC, lists the assumptions, and the artifact renders a SYNTHETIC DATA badge. The starter example works this way.

**Why does the Prime zone only hold one number?**
For a wall display at three meters the reader has three to five seconds. One number and one state is what lands. Everything else is Support.

**What are the evidence labels on screen?**
VERIFIED and CORROBORATED metrics render without a label. STATED (client targets), INFERENCE (derived), and UNCORROBORATED (single undated source) render their label inside the component so a reader never mistakes a claim for a measurement.

**Why is there a ticker that says AMBIENT?**
The Stream zone may carry atmosphere. It is marked `data-decorative="true"`, hidden from assistive technology, and never placed where it could be read as signal. Remove it if the reader does not want it.

**Can I use my brand colors?**
Yes. SP-3 maps them into the accent role and computes contrast against the language's panel token. Sub-floor pairs need a logged exception you approve.

**Does the dashboard need a build step or a server?**
No. It opens from `file://`. Chart.js is loaded from cdnjs, pinned. If the CDN is unreachable an inline SVG fallback renders and a console warning is logged.

**Why does the QA agent run in a fresh context?**
So the builder never gates its own output. SP-10 is a checklist issued by `helm-qa` with no memory of the build.

**Why are typeface attributions marked UNCORROBORATED?**
Screen typeface attributions are contested even for the most studied interfaces. HELM specifies type categories and ships open-license faces in those categories, never the originals or fan recreations.

**Can HELM build a people-tracking interface?**
No. The Sonar-Surveillance language is a grammar for system and network state only.

**How do I add a sixteenth language?**
Edit `data/canonical/catalog.json`, add a matching rule or an override note, run the validator and the builders, and update the count law in the schema and validator deliberately. The count law exists so this is a decision, not an accident.
