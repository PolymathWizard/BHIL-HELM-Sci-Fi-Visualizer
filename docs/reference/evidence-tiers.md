# Evidence Classification Standard

The five-tier vocabulary is shared across every BHIL framework and propagates faithfully. Order is fixed. Every headline metric on a HELM screen either carries VERIFIED or CORROBORATED, or shows its class label on screen.

| Rank | Tier | Definition | HELM application | On-screen label required |
|---|---|---|---|---|
| 1 | VERIFIED | Primary source, named, dated | System-of-record extracts; designer-stated facts in on-record interviews | no |
| 2 | CORROBORATED | Two or more independent sources agree | Studio credits confirmed across trade press; two data extracts reconciled | no |
| 3 | UNCORROBORATED | Single source, undated, or unnamed | Single export; typeface attributions from fan wikis | yes |
| 4 | INFERENCE | Analyst reasoning from incomplete data | Derived metrics; estimated ranges; language-fit rationale | yes |
| 5 | STATED | Self-reported, client-claimed, or vendor-claimed; quarantined until reconciled | Client targets, benchmarks, self-reported rates; vendor performance claims | yes |


## SYNTHETIC

Row generated by HELM when the input is narrative only. Not an evidence tier. Every synthetic row carries this flag and the assumption that produced it.

## Why this is load-bearing

Claim degradation is invisible at the variant level. A hedge stripped during compression looks like confidence. Structural enforcement (the label travels with the number in the data file and the render function refuses to draw a headline without one) is the only reliable counter.
