# Changelog

## 1.0.0 (2026-08-27)

Initial release of BHIL-HELM.

- Ten-prompt system: master prompt plus SP-1 through SP-10
- Canonical catalog of 15 original design languages with token sets, motion grammar, and study-only lineage
- Narrative Tax Register (12 tropes), evidence tiers (5), matching logic (11 rules), component contract (14 components, 6 zones)
- Lineage register distilled from three research documents, evidence-tagged, with design houses as first-class entities
- Generated `tokens/*.css` with drift gate
- CADRE agent scaffold: four tool-restricted subagents, six slash commands, one skill, settings
- Starter dashboard (Tactical HUD, SYNTHETIC data) with full client scaffold and offline chart fallback
- Templates for artifact, `CLAUDE.md`, `REGENERATE.md`, and client skill
- Stdlib-only validators: schema, count laws, cross-references, contrast floors, register, drift, em-dash sweep
- 19 regression tests, MkDocs Material site, GitHub Actions quality gate and Pages deploy
